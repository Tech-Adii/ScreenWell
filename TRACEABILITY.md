# Design-thinking traceability

Source: the supplied ScreenWell project survey, N = 91. Percentages are user-supplied research inputs, not independently validated health evidence. Reports of discomfort are self-reported.

| Finding                                            | Design response                            | Implementation                                                                            |
| -------------------------------------------------- | ------------------------------------------ | ----------------------------------------------------------------------------------------- |
| 52.7% use laptops/PCs 4+ hours/day                 | Sustainable, configurable rhythm           | Main-process scheduler, quiet hours, presets, custom timing                               |
| 60.4% report tired/dry eyes                        | Eye rest, blink awareness, optional camera | 20-20-20, eye exercises, local EAR calibration and rate window                            |
| 47% report neck/shoulder discomfort                | General movement and posture awareness     | Neck/shoulder guides, personal baseline, timed check-ins                                  |
| 70.3% skip breaks due to focus, workload, classes  | Fit around work and return gently          | Important task mode, welcome-back flow, snooze, typing pause inside app                   |
| 73.6% want wait/snooze/off controls                | User control is a hard requirement         | All reminder types expose now/snooze/skip/off; no locks or forced break                   |
| 39.6% prefer pop-up with snooze/dismiss            | Pop-up is default                          | In-app card or background `showInactive()` window                                         |
| 29.7% prefer full-screen; 23.1% small notification | Choice of presentation                     | Large in-app card and compact pop-up, always dismissible                                  |
| 34.1% prefer 45–60 min                             | Sensible default                           | 45-minute default                                                                         |
| 27.5% prefer 20–30 min                             | Shorter rhythms                            | 20-20-20 and 25/5 Pomodoro                                                                |
| 24.2% want own timing; 14.3% prefer 90 min         | Flexible cadence                           | Custom 1–240-minute break timing and 90-minute onboarding choice                          |
| Break reminders interest: 62.6%                    | Core feature first                         | Scheduler, five reminder types, adaptive interval suggestion                              |
| Water interest: 45.1%                              | Personal hydration habit                   | Active hours, editable goal, one-click logs, gentle nudges and streak                     |
| Stretch interest: 38.5%                            | Low-friction movement                      | Sixteen offline guides, seated alternatives, 2–5-minute coach                             |
| Webcam posture interest: 37.4%                     | Optional personal feedback                 | Baseline-relative face/pose heuristics, sustained hold and cooldown                       |
| Webcam comfort 2.79/5; 39.6% rate 1–2              | Privacy and camera-free parity             | Off by default and every launch; explicit consent; no recordings; complete timer fallback |
| Daily report interest: 30.8%                       | Reflect without guilt                      | Real charts, accessible table, local PDF/CSV, transparent score, badges                   |
| Desk setup interest: 16.5%                         | Optional lower-priority guide              | Illustrated, checkable five-step guide and relative distance cue                          |
| Design thinking: Prototype and Test                | Explain design and collect feedback        | In-app “Why this feature?”, isolated mentor demo, local feedback                          |

Inclusion and safety are product constraints: larger text, high contrast, reduced motion, keyboard access, screen-reader labels, explicit missing values, optional camera, and non-medical language. The habit score, badges, and demo are project enhancements, not direct survey findings.
